# Frontend Review Routing

Use the smallest set that matches the frontend change.

| Change | Skills |
|---|---|
| React/Next performance | `vercel-react-best-practices`, `code-review`, `verification-loop` |
| Component API/composition | `react-composition-patterns`, `code-review`, `test-review` |
| Responsive/mobile web UI | `web-design-review`, `mobile-web-acceptance`, `test-review` |
| Accessibility or UX audit | `web-design-review`, `mobile-web-acceptance` |
| React Native/Expo app | `react-native-review`, `code-review`, `test-review`, `verification-loop` |

Browser-based mobile support and native mobile support are separate acceptance
targets. Do not claim native mobile coverage from a responsive browser test.
